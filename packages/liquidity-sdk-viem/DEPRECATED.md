# Deprecated

`@morpho-org/liquidity-sdk-viem` is deprecated. This is its final release.

The package remains on Vault V1 PublicAllocator and is tested against
`@morpho-org/morpho-sdk@5.9.0`. Do not use it for new integrations; use the Vault V2
BluePublicAllocator APIs in `@morpho-org/morpho-sdk` instead.
